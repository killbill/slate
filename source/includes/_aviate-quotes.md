# Aviate Quotes

A quote is a priced proposal for a [billing account](aviate-billing-accounts.html): a list of items, each adding a plan, changing the plan of an existing subscription or canceling one, with optional price overrides and discounts. A quote moves from draft to sent to accepted; submitting an accepted quote creates, changes or cancels the Kill Bill subscriptions, and records an order and a contract. This section documents the APIs to create and manage quotes, and the people related to them.

## Before You Begin

### Authentication

The Aviate Plugin uses a JWT based authentication mechanism. Thus, all the APIs listed in this document require a valid token. This can be obtained via the [Auth API](aviate-auth.html).

When Aviate permission checks are enforced (`com.killbill.billing.plugin.aviate.auth.permissions.mode=enforce`, `off` by default), each endpoint below requires the permissions listed in its section, and returns a status code of 403 when the caller's role does not have them. See [Aviate Access Control](https://docs.killbill.io/latest/aviate-access-control) for roles and permissions.

### Tenancy

Each endpoint requires the standard Kill Bill `X-Killbill-ApiKey` and `X-Killbill-ApiSecret` headers, which identify the tenant.

### Content Type

Send `Content-Type: application/json` with every `POST`, including the ones that have no request body (such as [Mark a Quote as Sent](#mark-a-quote-as-sent)). Without it, Kill Bill rejects the request with a status code of 400.

### Quote Status

A quote is created as `DRAFT`. Its status then changes as follows:

| Status | Can change to | Using |
|--------|---------------|-------|
| `DRAFT` | `SENT`, `CANCELED`, `EXPIRED`, `SUPERSEDED` | [Mark as Sent](#mark-a-quote-as-sent), [Cancel](#cancel-a-quote), [Change the Status](#change-the-status-of-a-quote), [New Version](#create-a-new-version-of-a-quote) |
| `SENT` | `ACCEPTED`, `REJECTED`, `CANCELED`, `EXPIRED`, `SUPERSEDED` | [Mark as Accepted](#mark-a-quote-as-accepted), [Change the Status](#change-the-status-of-a-quote), [Cancel](#cancel-a-quote), [New Version](#create-a-new-version-of-a-quote) |
| `ACCEPTED` | `SUBMITTED`, `CANCELED`, `REJECTED`, `SUPERSEDED` | [Submit](#submit-a-quote), [Cancel](#cancel-a-quote), [Change the Status](#change-the-status-of-a-quote), [New Version](#create-a-new-version-of-a-quote) |
| `SUBMITTED`, `CANCELED`, `REJECTED`, `EXPIRED`, `SUPERSEDED` | - | Final |

Only a `DRAFT` quote can be updated or have items deleted. A quote whose `expiresAt` date has passed can no longer be sent or accepted.

## Resources

This section lists the models used by the Aviate quote APIs. A field that is not set is returned as an empty string, `0` or `false`.

### Quote

| Name | Type | Description |
|------|------|-------------|
| **quoteId** | string (UUID) | Unique identifier of the quote, generated by Aviate |
| **billingAccountId** | string (UUID) | Billing account of the quote |
| **status** | string | `DRAFT`, `SENT`, `ACCEPTED`, `SUBMITTED`, `CANCELED`, `REJECTED`, `EXPIRED` or `SUPERSEDED`. See [Quote Status](#quote-status). Set by Aviate |
| **currency** | string | Currency of the quote, as an ISO 4217 code (for example `USD`) |
| **header** | string | Text shown at the top of the quote |
| **footer** | string | Text shown at the bottom of the quote |
| **netTermsPeriod** | string | Payment terms shown on the quote (for example `NET30`) |
| **expiresAt** | string (date-time) | Date and time after which the quote can no longer be sent or accepted |
| **sentAt**, **acceptedAt**, **canceledAt** | string (date-time) | When the quote was sent, accepted or canceled. Set by Aviate |
| **version** | integer | Version of the quote, starting at 1. Set by Aviate |
| **parentQuoteId** | string (UUID) | For a new version, the quote it replaces. Set by Aviate |
| **couponCode** | string | Coupon code recorded on the quote |
| **items** | list of QuoteItem | Items of the quote |
| **relatedParties** | list of RelatedParty | People and organizations related to the quote. See [Related Party APIs](#related-party-apis) |
| **computed** | object | `quoteTotals`: the QuoteTotals of the quote. Computed by Aviate |

### QuoteItem

| Name | Type | Description |
|------|------|-------------|
| **quoteItemId** | string (UUID) | Unique identifier of the item, generated by Aviate |
| **quoteId** | string (UUID) | Quote of the item. Set by Aviate |
| **action** | string | What submitting the quote does with this item: `ADD` (create a subscription), `MODIFY` (change the plan of `targetSubscriptionId`), `DELETE` (cancel `targetSubscriptionId`) or `NO_CHANGE`. `NO_CHANGE` is the default, and is submitted like `ADD` |
| **targetSubscriptionId** | string (UUID) | For `MODIFY` and `DELETE`: the Kill Bill subscription to change or cancel |
| **planName** | string | Kill Bill catalog plan. Must exist in the tenant's catalog |
| **productName** | string | Product of the plan. Optional; when given, it must be the product of `planName` |
| **quantity** | integer | Number of units. `0` counts as 1 |
| **bcd** | integer | Bill cycle day of the subscription |
| **entitlementEffectiveDate**, **billingEffectiveDate** | string (date-time) | When the subscription (or the plan change, or the cancellation) takes effect. The submit date when not set |
| **termPeriod** | string | Committed term, as an ISO 8601 period (for example `P1Y`) |
| **autoRenew** | boolean | Whether the subscription renews at the end of `termPeriod`. When `false` and `termPeriod` is set, the subscription is canceled at the end of the term |
| **renewalPeriod** | string | Renewal period, as an ISO 8601 period, for the contract |
| **cancellationNoticePeriod** | string | Notice needed to cancel before a renewal, as an ISO 8601 period, for the contract |
| **initialCredit** | string (decimal) | Initial credit amount, for the contract |
| **recurringCredit**, **recurringCreditPeriod**, **recurringCreditTerm** | string | Not supported yet: a quote with a `recurringCredit` is rejected |
| **prices** | list of QuoteItemPrice | Prices of the item. Leave it out to use the catalog prices of the plan |
| **productOfferingId**, **offeringVersion**, **priceRefId**, **characteristicSelections** | | For items based on an Aviate product offering instead of a plan. `priceRefId` is then required, and `planName` must be empty |
| **priceSchedule** | list | Optional pricing periods (`periodLabel`, `periodStart`, `periodEnd`, `quantity`, `unitPrice`, `billingPeriod`), used for the `tcv`, `acv` and `arr` totals |
| **resolvedTaxCode**, **taxCodeSource**, **taxRate**, **itemTaxAmount** | string | Tax information of the item. Set by Aviate |

### QuoteItemPrice

| Name | Type | Description |
|------|------|-------------|
| **quoteItemPriceId** | string (UUID) | Unique identifier of the price, generated by Aviate. Empty for catalog prices shown for an item without prices |
| **priceType** | string | `FIXED`, `RECURRING` or `USAGE` |
| **amount** | string (decimal) | Price, replacing the catalog price of the same type and phase |
| **currency** | string | Currency of the price. It must be one of the plan's currencies |
| **phaseType** | string | Plan phase of the price (for example `EVERGREEN`). Set from the plan when not given |
| **description** | string | Description of the price |
| **alterations** | list of QuoteItemPriceAlteration | Discounts and surcharges applied to `amount` |
| **usageTierOverrides** | list | For `USAGE` prices: per-tier prices (`usageName`, `tierNumber`, `billingMeterCode`, `amount`, `currency`, `alterations`) |

### QuoteItemPriceAlteration

| Name | Type | Description |
|------|------|-------------|
| **alterationId** | string (UUID) | Unique identifier of the alteration, generated by Aviate |
| **alterationType** | string | `DISCOUNT` or `SURCHARGE` |
| **applicationMethod** | string | `PERCENTAGE` (a percentage of the price) or `ABSOLUTE` (an amount) |
| **value** | string (decimal) | Percentage or amount |
| **reason** | string | Reason for the alteration |

### QuoteTotals

Computed by Aviate from the item prices, quantities and alterations.

| Name | Type | Description |
|------|------|-------------|
| **oneTime** | string (decimal) | Total of the fixed (one-time) prices |
| **monthlyRecurring** | string (decimal) | Total recurring amount per month |
| **annualRecurring** | string (decimal) | Total recurring amount per year |
| **annualizedDealValue** | string (decimal) | Annualized value of the quote |
| **discountAmount** | string (decimal) | Total discount per period |
| **grandTotal** | string (decimal) | One-time total plus annual recurring total |
| **tcv**, **acv**, **arr** | string (decimal) | Total contract value, annual contract value and annual recurring revenue, for items with a `priceSchedule` |
| **taxAmount**, **taxLines** | | Tax on the quote, in total and by tax code |

### Order

Returned when a quote is submitted.

| Name | Type | Description |
|------|------|-------------|
| **orderId** | string (UUID) | Unique identifier of the order |
| **billingAccountId** | string (UUID) | Billing account of the quote |
| **quoteId** | string (UUID) | Submitted quote |
| **po** | string | Purchase order number given at submit |
| **status** | string | Status of the order (`ACTIVE` when created) |
| **orderSubscriptions** | list | For each item: `orderSubscriptionId`, `orderId`, `quoteItemId`, `subscriptionId` (the Kill Bill subscription created, changed or canceled) and `consumedCredit` |
| **characteristics** | list | Characteristics selected on product offering items |

### RelatedParty

| Name | Type | Description |
|------|------|-------------|
| **relatedPartyId** | string (UUID) | Unique identifier of the related party, generated by Aviate |
| **entityType** | string | `QUOTE`. Set by Aviate |
| **entityId** | string (UUID) | Quote of the related party. Set by Aviate |
| **role** | string | `BUYER`, `SELLER`, `APPROVER`, `RESELLER` or `END_USER` (any case). Required |
| **partyType** | string | Type of party, for example `INDIVIDUAL` or `ORGANIZATION` |
| **partyId** | string | Identifier of the party in your systems, up to 36 characters |
| **name** | string | Name |
| **email** | string | Email address |

## Quote APIs

### Create a Quote

Creates a quote in `DRAFT` status for a billing account.

Each item references a plan of the tenant's catalog. An item without `prices` uses the catalog prices of its plan; a price in `prices` replaces the catalog price of the same type, and its `alterations` (discounts, surcharges) apply on top. Related parties given in `relatedParties` are added to the quote.

**HTTP Request**

`POST /plugins/aviate-plugin/v1/quote`

> Example Request:

```shell
curl -X POST \
     -H "Authorization: Bearer ${ID_TOKEN}" \
     -H 'X-Killbill-ApiKey: bob' \
     -H 'X-Killbill-ApiSecret: lazar' \
     -H 'Content-Type: application/json' \
     -d '{
           "billingAccountId": "7dd70679-4069-4a88-864e-a34726e96c9b",
           "currency": "USD",
           "header": "Proposal for Acme Corp",
           "footer": "Prices exclude tax.",
           "expiresAt": "2026-12-25T00:00:00Z",
           "netTermsPeriod": "NET30",
           "items": [
             {
               "action": "ADD",
               "productName": "Analytics",
               "planName": "analytics-basic-monthly",
               "quantity": 1,
               "prices": [
                 {
                   "priceType": "RECURRING",
                   "currency": "USD",
                   "amount": "90.00",
                   "alterations": [
                     {
```

### Update a Quote

Updates a quote in `DRAFT` status and its items.

Only the fields given are changed: a quote or item field that is left out (or empty) keeps its value, except `autoRenew`, which is set to `false` when left out. In `items`:

* an item with a `quoteItemId` updates that item; its prices are replaced when `prices` is given, and kept otherwise;
* an item without a `quoteItemId` is added to the quote;
* the items that are not in the request are kept. Use [Delete a Quote Item](#delete-a-quote-item) to remove one.

**HTTP Request**

`POST /plugins/aviate-plugin/v1/quote/{quoteId}`

> Example Request:

```shell
curl -X POST \
     -H "Authorization: Bearer ${ID_TOKEN}" \
     -H 'X-Killbill-ApiKey: bob' \
     -H 'X-Killbill-ApiSecret: lazar' \
     -H 'Content-Type: application/json' \
     -d '{
           "header": "Proposal for Acme Corp (revised)",
           "items": [
             {
               "quoteItemId": "57a1ff07-6d6f-4092-83f6-937b17510000",
               "action": "ADD",
               "productName": "Analytics",
               "planName": "analytics-basic-monthly",
               "quantity": 2
             },
             {
               "action": "ADD",
               "productName": "Analytics",
               "planName": "analytics-premium-monthly",
               "quantity": 1
             }
           ]
         }' \
     'http://127.0.0.1:8080/plugins/aviate-plugin/v1/quote/ba7a9d97-deba-483b-bc48-9379e10f134e'
```

### Submit a Quote

Submits a quote in `ACCEPTED` status. For each item, in the billing account's Kill Bill account:

* `ADD` and `NO_CHANGE` items create a subscription, with the item's prices, quantity, bill cycle day and effective dates;
* `MODIFY` items change the plan of `targetSubscriptionId`;
* `DELETE` items cancel `targetSubscriptionId`.

Aviate then records an order (returned) and a contract, and the quote changes to `SUBMITTED`. If a step fails, the subscriptions created by the submit are canceled.

To retry a submit safely, send an `Idempotency-Key` header: a submit with a key that already completed returns the order of that submit. The key is checked across the tenant, so use a different key for each quote.

**HTTP Request**

`POST /plugins/aviate-plugin/v1/quote/{quoteId}/submit`

> Example Request:

```shell
curl -X POST \
     -H "Authorization: Bearer ${ID_TOKEN}" \
     -H 'X-Killbill-ApiKey: bob' \
     -H 'X-Killbill-ApiSecret: lazar' \
     -H 'Content-Type: application/json' \
     -H 'Idempotency-Key: submit-389a5488' \
     'http://127.0.0.1:8080/plugins/aviate-plugin/v1/quote/389a5488-9c02-4edb-b95e-508027fb5223/submit?po=PO-1001'
```
